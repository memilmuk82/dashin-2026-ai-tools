한 건의 API 비용은 사용량으로 계산

월 구독료와 호출 비용은 다른 항목입니다.

  • 입력 토큰 + 출력 토큰을 따로 계산
  • 실제 응답 usage로 한 건을 기록
  • 반복 호출·재시도 횟수도 비용에 포함

확인할 것실제 사용량이 있어야 실제 1건 비용을 쓸 수 있다.

한 건 비용 =

입력량 × 입력 단가
+ 출력량 × 출력 단가

기본 계산 예: 1,000 입력 + 500 출력, $0.30/$1.20(100만 토큰당) → $0.0009, 세금·환율 제외. 실측 아님.
