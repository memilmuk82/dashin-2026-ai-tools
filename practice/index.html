첫 제작

복사해서 요청하기

교사의 반복 업무를 돕는 ‘행사 안내문 도구’를 만들어 줘.
HTML 파일 하나로, 별도 설치나 로그인 없이 브라우저에서 열리게 해 줘.
입력: 행사명, 날짜·시간, 장소, 대상, 준비물, 확인이 필요한 사항.
버튼을 누르면 위 입력을 정해진 안내문 틀에 넣고, 결과 복사·입력 초기화·인쇄를 제공해 줘.
지금은 AI API를 연결하지 말고 입력값을 조합해서 동작하게 해 줘.
입력하지 않은 날짜·비용·담당자·평가 기준을 만들어 내지 말고 ‘확인 필요’로 표시해 줘.
학생·교사 개인정보와 비공개 평가자료는 사용하지 않을 거야.
휴대전화에서도 글자가 잘 보이고 버튼을 누를 수 있게 해 줘.
내가 조작할 순서를 쉬운 한국어로 알려 주고 실행 가능한 미리보기를 보여 줘.

‘준비물’이 없는 경우 준비물을 추측해서 추가하지 마.
결과 복사 버튼에 성공 또는 실패 안내를 넣고, 모바일에서 가로로 잘리지 않게 해 줘.
이전 기능은 유지하고 내가 확인할 테스트 3가지를 알려 줘.

기존 앱에 Solar 연결 추가

복사해서 요청하기

이전에 만든 행사 안내문 웹앱에 Upstage Solar 연결 기능을 추가해 줘.
나는 코드를 직접 수정하지 않고 사용 방법만 안내받을 거야. 기존 입력 조합 기능은 유지해 줘.
‘연습용 예시’와 ‘Solar 실제 호출’을 분리하고, 기본은 예시 모드로 시작해 줘.
실제 호출에는 API 키를 현장에서 직접 입력하는 비밀번호 형식 입력칸을 추가해 줘. 키 문자열을 지금 대화에 넣지는 않을 거야.
키는 메모리에서만 사용하고 파일·브라우저 저장소·URL·화면 출력·콘솔·오류문에 넣지 마. 새로고침하거나 ‘키 지우기’를 누르면 없어지게 해 줘.
2026-10-28 공식 안내 기준 모델은 solar-pro4, 요청 주소는 https://api.upstage.ai/v1/chat/completions 이야. 공식 안내가 바뀌면 실제 확인한 값만 사용해 줘.
사용자가 실제 호출 버튼을 눌렀을 때만 입력한 행사 정보를 Upstage에 보내 안내문 초안을 받게 해 줘. 한 번 클릭에 한 번만 요청하고 중복 클릭·자동 재시도는 막아 줘.
입력하지 않은 사실은 ‘확인 필요’로 유지하고, 결과는 HTML로 실행하지 말고 일반 글자로 보여 줘.
완료 안내, 30초 시간 초과, 키 오류, 사용량 한도, 모델 오류, 네트워크/CORS 실패 안내를 쉬운 한국어로 보여 줘. CORS라고 단정하지 말고 네트워크 차단도 확인하도록 해 줘.
실패해도 예시 모드와 결과 복사·인쇄를 계속 쓸 수 있게 해 줘. 백엔드나 우회 서버를 새로 만들지 마.
이 구조는 연수 체험용이며 프론트의 키는 노출될 수 있음을 알려 줘. 연수용 임시키는 2026-10-30 강사가 폐기할 예정이라고 표시해 줘.
완료 후 내가 누를 순서와 정상 결과 확인 방법을 알려 줘.

안전한 오류 대응

복사해서 요청하기

오류가 발생했어. 비밀키나 개인정보를 제외한 화면의 오류 안내는 다음과 같아: [여기에 안전한 오류 안내만 입력]
현재 화면과 입력 조합 기능은 유지해 줘. 키·입력 원문·요청 헤더를 출력하지 마.
사용자가 확인할 순서를 쉬운 한국어로 알려 줘. CORS/네트워크 문제라면 보안 설정을 끄거나 출처 불명 중계 서버로 보내지 말고 예시 모드를 안내해 줘.
백엔드를 추가하는 방향으로 범위를 바꾸지 마.
