first
교사의 행사 안내문 웹앱을 만들어 줘.
입력: 행사명·날짜와 시간·장소·대상·준비물. 만들기·복사·초기화·인쇄 버튼.
처음부터 ‘예시/Solar’ 선택, 가려진 API 키 입력칸, ‘Solar 실행’·‘키 지우기’를 넣어 줘.
예시는 입력값 조합, Solar는 입력한 행사 정보로 안내문 생성. 빈 날짜·장소는 ‘확인 필요’.
Solar 모델 solar-pro4, 주소 https://api.upstage.ai/v1/chat/completions 를 사용해 줘.
키는 완성 앱에서 입력하고 인증에만 써. 저장·URL·결과·로그에 넣지 마.
Solar 실행을 누를 때만 1회 호출하고, 실제 응답 표시·사용량·쉬운 오류 안내를 보여 줘.
연결 실패 시 예시로 돌아가게 해 줘. 백엔드 없이 단일 HTML·모바일을 지원해 줘.

revise
지금 만든 행사 안내문 도구를 수정해 줘.
장소를 비워 두면 결과에 ‘장소: 확인 필요’가 나오게 해 줘.
날짜·시간과 장소가 바뀌면 새 결과에 정확히 반영되어야 해.
‘준비물’이 없는 경우 준비물을 추측해서 추가하지 마.
결과 복사 버튼에 성공 또는 실패 안내를 넣고, 모바일에서 가로로 잘리지 않게 해 줘.
이전 기능은 유지하고 내가 확인할 테스트 3가지를 알려 줘.

api
지금 만든 같은 앱의 Solar 연결을 점검하고 고쳐 줘.
예시/Solar 선택·가려진 키 입력칸·Solar 실행·키 지우기가 보이게 해 줘.
모델 solar-pro4, 주소 https://api.upstage.ai/v1/chat/completions 를 확인해 줘.
키는 앱에서 입력하고 인증에만 사용해. 저장·URL·결과·로그에 출력하지 마.
실행 버튼 1회에만 요청하고 실제 응답·사용량·쉬운 오류 안내를 표시해 줘.
기존 입력·복사·인쇄·예시를 유지하고 백엔드·우회 서버는 만들지 마.
내가 확인할 순서와 정상 결과를 알려 줘.

fix
오류가 발생했어. 비밀키나 개인정보를 제외한 화면의 오류 안내는 다음과 같아: [여기에 안전한 오류 안내만 입력]
현재 화면과 입력 조합 기능은 유지해 줘. 키·입력 원문·요청 헤더를 출력하지 마.
사용자가 확인할 순서를 쉬운 한국어로 알려 줘. CORS/네트워크 문제라면 보안 설정을 끄거나 출처 불명 중계 서버로 보내지 말고 예시 모드를 안내해 줘.
백엔드를 추가하는 방향으로 범위를 바꾸지 마.

solar-chat
교사가 검토할 행사 안내문 초안을 써 주세요.
행사명: 교원 AI 도구 나눔 / 대상: 희망 교원 / 준비물: 노트북
날짜·시간과 장소는 ‘확인 필요’로 남겨 주세요.
입력하지 않은 담당자·비용 등은 추가하지 말아 주세요.
