Gemini Canvas로 만들기

Google 계정으로 접속하고 Canvas를 사용할 수 있는 분에게 맞는 경로입니다.

  1. 자료 선택 →원문 제목·연도·출처와 사용할 범위를 기록합니다.
  2. 입력·결과와 첫 요청 →업무에 맞춘 첫 제작 요청을 전송하고, 입력·실행·결과가 있는 앱을 받습니다.
  3. Canvas 선택부터 제작·수정·저장 →Canvas 앱에 가상 입력을 넣고, 빈 날짜·장소의 확인 필요 표시를 확인합니다.
  4. 한 가지 수정과 재검사 →수정 전 문제·수정 요청·다시 시험한 결과를 남깁니다.
  5. 복사·모바일·인쇄 검사 →입력 반영·누락 처리·복사·작은 화면·인쇄의 통과 여부와 남은 문제를 기록합니다.
이 경로의 완료 기준

입력을 바꾸면 새 결과가 나오고, 빈칸은 확인 필요로 남고, 복사한 결과가 붙여 넣어집니다. 남은 오류와 다음 수정 한 가지를 기록합니다.

Claude Artifacts로 만들기

Claude에 로그인해 웹앱 Artifact를 만들 수 있는 분에게 맞는 경로입니다.

  1. 자료 선택 →원문 제목·연도·출처와 사용할 범위를 기록합니다.
  2. 입력·결과와 첫 요청 →업무에 맞춘 첫 제작 요청을 전송하고, 입력·실행·결과가 있는 앱을 받습니다.
  3. Artifact 요청부터 입력·생성·복사·저장 →Artifact 안의 앱을 직접 실행하고 입력 반영·누락 표시·복사를 검사합니다.
  4. 한 가지 수정과 재검사 →수정 전 문제·수정 요청·다시 시험한 결과를 남깁니다.
  5. 모바일·인쇄와 결과 기록 →입력 반영·누락 처리·복사·작은 화면·인쇄의 통과 여부와 남은 문제를 기록합니다.

  2. 가상 자료와 안전 범위 확인 →원문 제목·연도·출처와 사용할 범위를 기록합니다.
  3. 입력·빈칸·복사·모바일·인쇄 검사 →입력 반영·누락 처리·복사·작은 화면·인쇄의 통과 여부와 남은 문제를 기록합니다.

내 도구에 Solar 연결 체험

첫 앱의 입력·결과 검사를 마친 뒤 선택합니다. 실제 키는 현장에서 앱 입력칸에만 넣습니다.

  1. 기존 대화에 연결 기능 추가 요청 →기존 예시 모드를 유지하면서 Solar 연결에 필요한 화면을 갖춥니다.
  2. 빈 키 입력칸·자료 확인·한 번 호출 →실제 호출을 준비하고, 촬영·저장 전 키를 지우는 습관을 익힙니다.
  3. 실제 응답과 사실 검토 →실제 응답/예시를 구분하고 사실·누락·표현을 검토합니다.
  4. 오류별 확인과 예시·무료 채팅 전환 →오류에 맞는 확인을 하거나 예시·무료 채팅으로 실습을 이어갑니다.
  5. 한 건 비용 →계산 예시와 실제 한 건 비용을 구분합니다.
  6. 키 지우기와 폐기 계획 →체험 도구를 키가 포함된 공개 서비스로 그대로 배포하지 않습니다.
이 경로의 완료 기준

실제 응답인지 예시인지 구분하고, 키를 지우며 실패 시 대체 경로로 돌아갈 수 있습니다.
